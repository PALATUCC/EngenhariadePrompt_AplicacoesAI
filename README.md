## 📖 Sobre o Projeto

Repositório dedicado às **atividades práticas** da disciplina de **Engenharia de Prompt e Aplicações em IA**. 

Este espaço é um ambiente colaborativo para explorar o potencial das tecnologias de IA, combinando engenharia de prompts com soluções low-code e no-code para criar aplicações inovadoras.

<div align="center">

**Aprender fazendo. Inovar praticando. IA em ação! 🤖**

</div>

```bash

```
